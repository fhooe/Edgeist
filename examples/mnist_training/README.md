# Minimal Edgeist MNIST training example

This folder is meant to be copied directly into the Edgeist repository and run from the normal Edgeist CMake workspace.

The example builds one executable:

```text
edgeist-mnist-training
```

It trains the included tiny MNIST-shaped Edgeist model on the first `N` records from:

```text
mnist_train_all_random.bin
```

`N` is the only command-line argument.

The included `mnist_train_all_random.bin` is a 5-record smoke-test fixture. It is not the full MNIST dataset. It exists so you can immediately test that the C++ example is wired into the workspace correctly.

## 1. Copy the example into Edgeist

Your Edgeist checkout should look like this after copying the folder:

```text
edgeist/
  CMakeLists.txt
  CMakePresets.json
  runtime/
  examples/
    desktop/
    embedded/
    mnist_training/
      CMakeLists.txt
      README.md
      main_example.cpp
      model.hex
      model_trainable.hex
      mnist_train_all_random.bin
```

From a terminal, copy the folder like this:

```bash
cd path/to/edgeist
mkdir -p examples/mnist_training
cp path/to/mnist_training_workspace_tiny/* examples/mnist_training/
```

Then open the Edgeist repository root in your editor:

```bash
code .
```

Open these files:

```text
CMakeLists.txt
examples/mnist_training/main_example.cpp
examples/mnist_training/README.md
```

## 2. Add it to the top-level CMake workspace

In the top-level `CMakeLists.txt`, find this block:

```cmake
if(EDGEIST_BUILD_EXAMPLES)
    add_subdirectory(examples/desktop)
    add_subdirectory(examples/embedded)
endif()
```

Add the new example folder:

```cmake
if(EDGEIST_BUILD_EXAMPLES)
    add_subdirectory(examples/desktop)
    add_subdirectory(examples/embedded)
    add_subdirectory(examples/mnist_training)
endif()
```

Save the file.

## 3. Configure and build the example

Run this from the Edgeist repository root:

```bash
cmake --preset host-debug
cmake --build --preset host-debug --target edgeist-mnist-training
```

The executable is created here:

```text
build/host-debug/examples/mnist_training/edgeist-mnist-training
```

The example's `CMakeLists.txt` copies these three input files into the same build folder:

```text
model.hex
model_trainable.hex
mnist_train_all_random.bin
```

That is why the executable can be run directly from the build folder.

## 4. Run the example manually

The program opens `model.hex`, `model_trainable.hex`, and `mnist_train_all_random.bin` from the current working directory.

Change into the build output folder:

```bash
cd build/host-debug/examples/mnist_training
```

Run one training update on the first record:

```bash
./edgeist-mnist-training 1
```

Expected output:

```text
loss: 2.30259
```

Run five training updates on the five included records:

```bash
./edgeist-mnist-training 5
```

Expected output:

```text
loss: 2.30659
```

The last digits can vary slightly by compiler.

After running, this file should exist in the same folder:

```text
model_trainable_after.hex
```

Check it:

```bash
ls -l model_trainable_after.hex
```

Confirm that training changed the trainable parameter file:

```bash
cmp -s model_trainable.hex model_trainable_after.hex \
  && echo "not changed" \
  || echo "changed: training updated the parameter file"
```

Expected:

```text
changed: training updated the parameter file
```

## 5. Run the CTest smoke test

Go back to the Edgeist repository root:

```bash
cd ../../../..
```

Run only this example's test:

```bash
ctest --test-dir build/host-debug -R edgeist_mnist_training_smoke --output-on-failure
```

Expected output:

```text
100% tests passed, 0 tests failed out of 1
```

The test runs:

```text
edgeist-mnist-training 5
```

from the build output folder, so the executable can find the copied `.hex` and `.bin` files.

## 6. What the C++ file does

`main_example.cpp` intentionally stays small:

```text
load model.hex
load model_trainable.hex
open mnist_train_all_random.bin
for each requested sample:
    read one MNIST record
    create one-hot target from the label
    begin_micro_batch()
    train_sample(...)
    apply_updates(1)
write model_trainable_after.hex
print final loss
```

One MNIST record is:

```text
784 little-endian float32 pixels
1 uint8 label
```

So one record is 3137 bytes. The included smoke-test file has five records, so it is 15685 bytes.

## 7. Replace the smoke-test data later

After the example runs, you can replace:

```text
examples/mnist_training/mnist_train_all_random.bin
```

with a real packed MNIST file generated by Edgeist's packer.

Then rebuild this target so CMake copies the new file into the build folder:

```bash
cd path/to/edgeist
cmake --build --preset host-debug --target edgeist-mnist-training
```

Run with the number of records you want to consume:

```bash
cd build/host-debug/examples/mnist_training
./edgeist-mnist-training 100
```

Do not request more records than the file contains. The included smoke-test file contains only five records.

## 8. Common errors

### `model.hex`

You ran the executable from the wrong directory.

Use:

```bash
cd build/host-debug/examples/mnist_training
./edgeist-mnist-training 1
```

### `mnist_train_all_random.bin`

The MNIST binary file is missing from the current directory.

Rebuild the target:

```bash
cmake --build --preset host-debug --target edgeist-mnist-training
```

Then run from:

```text
build/host-debug/examples/mnist_training
```

### `bad mnist_train_all_random.bin`

The file is truncated, has the wrong record format, or you requested too many records.

For the included smoke-test file, valid values are:

```bash
./edgeist-mnist-training 1
./edgeist-mnist-training 2
./edgeist-mnist-training 3
./edgeist-mnist-training 4
./edgeist-mnist-training 5
```

### `training was disabled at compile time`

You built with the inference-only preset. Reconfigure with:

```bash
cmake --preset host-debug
```
